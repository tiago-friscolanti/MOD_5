# 📞 Control Dinámico de Personal – Call Center

*Técnicas y Herramientas Modernas II · Módulo 5* · Ingeniería Industrial, FI UNCuyo (2026)

Simulación en *Vensim PLE* de un sistema que ajusta las contrataciones según la brecha entre el personal activo y la meta. Se pone a prueba con un shock: un nuevo cliente duplica la plantilla requerida en la semana 4.

*Resultado:* el sistema absorbe el shock sin oscilar, con un pico de contrataciones y un ajuste exponencial suave hacia la nueva meta.
